# dsh-plugins

Plugins for DeepSeek Harness (dsh) by Lbryany, plus the plugin market index. Each plugin lives under `packages/` and is tagged separately as `<dir>-v<version>`: `dsh-herdr`, `dsh-peer`, and `dsh-widget` (a fork of Nagi-ovo/dsh-visualize, not yet released). The market index generator lives in `market/`. The index is published at `https://lbryany.github.io/dsh-plugins/index.json`. See [README.zh.md](README.zh.md).
