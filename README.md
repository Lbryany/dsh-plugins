# dsh-plugins

Plugins for DeepSeek Harness (dsh) by Lbryany, plus the plugin market index. Each plugin lives under `packages/` and is tagged separately as `<dir>-v<version>`: `dsh-herdr`, `dsh-peer`, `dsh-widget` (a fork of Nagi-ovo/dsh-visualize), and `dsh-compaction-instruction` (a drop-in replacement for dsh-compaction-basic with a configurable summarization directive). The market index generator lives in `market/`. The index is published at `https://lbryany.github.io/dsh-plugins/index.json`. See [README.zh.md](README.zh.md).
